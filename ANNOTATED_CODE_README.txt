VACANSEE CODE EXPLANATION PACKAGE

The root folder contains the original working website files:
- index.html
- saved.html
- style.css
- script.js
- images/

The annotated-code folder contains line-by-line explanation copies:
- index.html.annotated.txt
- saved.html.annotated.txt
- style.css.annotated.txt
- script.js.annotated.txt

IMPORTANT:
The .annotated.txt files are study/reference copies. They place a matching
comment immediately before every source line. They are not intended to run
as website files. Keep using the original HTML, CSS and JavaScript files
from the project root for the functional website.

The accompanying PDF explains the project problem, objectives, features,
the role of each technology, and the overall code workflow.
